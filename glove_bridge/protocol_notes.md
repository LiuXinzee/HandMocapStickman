# 矩侨精密 织物电子皮肤 通讯协议笔记

## 数据帧格式

数据矩阵模板 = [帧头] + [包顺序] + [传感器类型] + [数据]

### 帧头
- 固定4字节: `0xAA 0x55 0x03 0x99`

### 包顺序
- `0x01` = 第一包
- `0x02` = 第二包

### 传感器类型
- `0x01` = LH (Left Hand)
- `0x02` = RH (Right Hand)
- `0x03` = LF (Left Foot)
- `0x04` = RF (Right Foot)
- `0x05` = WB (Whole Body)

### 数据
- 第一包(包顺序=0x01): 128字节 = 传感器前128个数据
- 第二包(包顺序=0x02): 144字节 = 传感器后128个数据 + 陀螺仪16个数据

### 完整帧结构
- 第一包: [AA 55 03 99] [01] [传感器类型] [128字节数据] = 4+1+1+128 = 134字节
- 第二包: [AA 55 03 99] [01] [传感器类型] [144字节数据] = 4+1+1+144 = 150字节
  - 注意：规格书中第二包的包顺序字段写的是0x02

### 波特率
- 921600 bps

## 关键发现
- 传感器数据总共 256 字节（两包合并: 128+128）
- 陀螺仪数据 16 字节（在第二包末尾）
- 索引从1开始（不是从0开始），最大256
- 手套实际有效传感点是 137 个（60压力+5弯折+72手掌），不是256个全部有效
